# Cibersegurança para iniciantes

## Objetivo
Este guia apresenta conceitos básicos de cibersegurança para pessoas sem conhecimento prévio, com linguagem simples e exemplos do cotidiano.

## Público-alvo
Pessoas que usam internet e celular todos os dias e querem aprender a se proteger melhor.

## Pré-requisitos
Nenhum conhecimento técnico prévio.
